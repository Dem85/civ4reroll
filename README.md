# Civ4Reroll

Автоматический «реролл» последнего сохранения **Civilization IV: Beyond the Sword**.

Программа сделана на основе проекта [`multikey/`](multikey/) (та же последовательность
действий для загрузки сохранения) и самостоятельно, по кругу:

1. выполняет сценарий загрузки последнего сохранения (`tmp.CivBeyondSwordSave`),
   пропускает несколько ходов и открывает летопись;
2. делает **скриншот летописи** — прямо перед тем `esc`, который её скрывает
   (в отличие от multikey этот esc в сценарий НЕ входит);
3. **читает летопись через скриншот** встроенным OCR Windows
   (`Windows.Media.Ocr`, без установки Tesseract) и ищет интересные события:
   - Золото: _«В шахте около города [Город] обнаружено золото!»_
   - Серебро: _«…обнаружено серебро!»_
   - Медь: _«…обнаружена медь!»_
   - Железо: _«…обнаружено железо!»_
   - Уголь: _«…обнаружен уголь!»_
   - Драгоценные камни: _«…обнаружены драгоценные камни!»_
4. если интересных событий **нет** — нажимает `esc` (скрывает летопись) и
   повторяет сценарий загрузки заново;
5. если событие **найдено** — сохраняет скриншот, закрывает летопись и
   останавливается.

Весь ход работы пишется в лог (`logs/civ4_reroll.log`) и в консоль.

## Требования

- Windows 10/11 (нужен встроенный OCR; работает через PowerShell 5.1+)
- Python 3.10+ (проверено на 3.13)
- Игра Civilization IV: BTS в **оконном режиме**

## Установка

```powershell
python -m pip install -r requirements.txt
```

Других зависимостей не нужно: клавиши шлются через Win32 `SendInput` (ctypes),
OCR — встроенный в Windows (скрипт [`scripts/ocr_windows.ps1`](scripts/ocr_windows.ps1)).

> Если русский OCR не работает (не распознаёт текст), проверьте, что в
> Windows установлен языковой пакет **русский**. Альтернативно можно
> использовать `ocr.engine = "tesseract"` (нужны `pip install pytesseract`
> и Tesseract OCR с русским языком) или `ocr.engine = "manual"` — программа
> будет показывать скриншот и спрашивать вас.

## Запуск

```powershell
# 1. Проверка: конфигурация, OCR, поиск событий (игру не трогает)
python -m app.main --selftest

# 2. Разбор готового скриншота летописи (без игры) — для настройки OCR
python -m app.main --check-image multikey/image.png

# 3. Одна попытка: сценарий -> скриншот -> анализ -> esc (удобно проверить)
python -m app.main --once

# 4. Полный цикл реролла (по кругу, пока не найдёт интересное событие)
python -m app.main
```

> ⚠️ Режимы `--once` и основной цикл посылают **реальные нажатия** в активное
> окно. Перед стартом переключитесь в окно игры: программа даст отсчёт
> `warmup_sec` секунд (по умолчанию 5).
> Остановить цикл можно через **Ctrl+C**.

Дополнительно:

| Команда | Что делает |
|---|---|
| `python -m app.main --config <путь>` | другой файл конфигурации (или переменная окружения `CIV4REROLL_CONFIG`) |
| `python -m app.main --once` | одна попытка и выход |
| `python -m app.main --selftest` | проверка конфигурации, OCR и поиска событий |
| `python -m app.main --check-image F.png` | распознать скриншот `F.png` и найти события |

## Конфигурация ([`config.json`](config.json))

```jsonc
{
  "game": {
    "window_title": null,          // строка = заголовок окна игры (активируется автоматически),
                                   // null = текущее активное окно
    "key_hold_sec": 0.02,
    "dpi_aware": false             // true, если скриншот/клики съезжают при масштабе Windows != 100%
  },
  "profile": {
    "name": "civ4-reroll",
    "actions": [ /* действия из multikey/config.json БЕЗ последнего esc */ ]
  },
  "events": {
    "context_keywords": ["шахт", "обнаруж"],   // обязательный контекст в предложении
    "fuzzy": true,                             // нечёткий поиск (устойчив к ошибкам OCR)
    "min_ratio": 0.8,
    "items": [                                 // интересные события (можно добавлять свои)
      { "name": "Золото", "keywords": ["золото"] },
      { "name": "Серебро", "keywords": ["серебро"] },
      { "name": "Медь", "keywords": ["медь"] },
      { "name": "Железо", "keywords": ["железо"] },
      { "name": "Уголь", "keywords": ["уголь"] },
      { "name": "Драгоценные камни", "keywords": ["драгоценные камни"] }
    ]
  },
  "ocr": {
    "engine": "auto",              // auto | windows | tesseract | manual
    "language": "ru-RU",
    "preprocess": true,            // градации серого + контраст + масштаб
    "max_image_dim": 2400
  },
  "screenshots": {
    "dir": "screenshots",
    "capture": "window",           // window (область окна, как в multikey) | fullscreen
    "keep_all_attempts": false,    // сохранять скриншот каждой попытки
    "save_success": true,          // копия при находке (success_001.png)
    "save_fail": false             // копии неудачных попыток
  },
  "loop": {
    "max_attempts": 0,             // 0 = бесконечно (до находки или Ctrl+C)
    "warmup_sec": 5.0,             // отсчёт перед стартом, чтобы переключиться в игру
    "pause_between_attempts_sec": 3.0,
    "esc_after_read_sec": 0.3      // пауза перед esc после чтения летописи
  },
  "log": { "dir": "logs", "file": "civ4_reroll.log", "level": "INFO" }
}
```

### Как добавить своё интересное событие

Добавьте пункт в `events.items`: `name` — как показать в логе, `keywords` —
слова, которые должны быть в одном предложении. Общий контекст задаётся в
`context_keywords` (по умолчанию «шахт» и «обнаруж»).

## Как это работает

1. `ActionRunner` ([`app/actions.py`](app/actions.py)) выполняет действия
   сценария через `SendInput` — точно как в multikey (координаты `relative`
   считаются от левого верхнего угла активного окна, включая заголовок).
2. После сценария летопись открыта, но ещё не закрыта `esc`.
3. [`app/screen.py`](app/screen.py) снимает скриншот области окна в той же
   системе координат.
4. [`app/ocr.py`](app/ocr.py) предобрабатывает картинку (серое, контраст,
   увеличение до 2×, ограничение 2400px для Windows OCR) и вызывает
   [`scripts/ocr_windows.ps1`](scripts/ocr_windows.ps1) — встроенный
   `Windows.Media.Ocr`.
5. [`app/events.py`](app/events.py) разбивает текст на предложения и ищет
   события (контекст + ключевые слова, нечёткое сравнение через `difflib`,
   извлечение названия города регуляркой).
6. Если события найдены — цикл останавливается; иначе `esc` и повтор.

## Частые проблемы

- **OCR возвращает пусто/мусор** — проверьте скриншот: `--check-image` на
  сохранённом `screenshots/latest.png`. Включите `preprocess: true`, либо
  переключитесь на `ocr.engine = "manual"`.
- **Клики/курсор не попадают** — игра должна быть в **оконном режиме**,
  разрешение окна должно совпадать с тем, под которое подстроены координаты
  в `profile.actions`. При масштабировании Windows ≠ 100% попробуйте
  `game.dpi_aware = true`.
- **Окно не то** — задайте `game.window_title` (например, `"Civilization IV"`).
- **Хочется остановить** — `Ctrl+C`.
